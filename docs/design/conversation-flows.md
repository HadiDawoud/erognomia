# Ergonomia — Conversation Flows

## Flow 1: Studierende/r sucht Projektinformationen

```
User: "Welche VR-Projekte gibt es im Lab?"
Bot:  "Das Lab betreibt aktuell mehrere Projekte im VR-Bereich:
       - INFUSE (Immersive Nutzerforschung in virtuellen Umgebungen)

       - SilentBedMonitor (VR-gestützte Schlafüberwachung)

User: "Erzähl mir mehr über INFUSE."
Bot:  "INFUSE steht für 'Immersive Nutzerforschung in virtuellen Umgebungen'.
       Das Projekt untersucht, wie Probanden in VR-Umgebungen auf verschiedene

```

